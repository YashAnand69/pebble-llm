    01 / ENCODE CHARACTERS

    A fixed vocabulary. Learned vectors.

    The tokenizer maps printable ASCII, newline, tab and four special tokens into 101 IDs. Each ID gets a learned 200-dimensional vector, plus a learned position embedding.

    101 tokens × 200 dimensions + 299 positions × 200 dimensionsInspect the tokenizer ↗
    01

    Read the characters

    A fixed vocabulary turns your question into character tokens. The model sees at most 299 characters of context.

    02

    Connect the context

    Four decoder blocks use causal attention. Each position learns from the characters that came before it.

    03

    Predict one more

    The tied output projection assigns probabilities to the next character. Temperature controls sampling.

    04

    Repeat and inspect

    Generation continues until the end token or the limit. Compare the output with the published evaluation.

    DEFINED AND TRAINED IN PEBBLE

    The whole learning loop is open.

    The network, tokenizer, training loop and sampling are Pebble programs. TensorFlow.js/WASM provides numerical kernels and automatic differentiation.
