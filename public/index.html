01 / ENCODE CHARACTERS

A fixed vocabulary. Learned vectors.

The tokenizer maps printable ASCII, newline, tab and four special tokens into 101 IDs. Each ID gets a learned 200-dimensional vector, plus a learned position embedding.

101 tokens × 200 dimensions + 299 positions × 200 dimensionsInspect the tokenizer ↗

Exactly two million.
No extra padding weights.

Four decoder blocks. Four attention heads. Width 200. A 299-position learned context. Input and output share the same token embedding. Eighteen unique trainable tensors, with no bias or dropout parameters.

Read the complete network ↗ 
// The complete parameter equation
(101 + 299) × 200
+ 4 × (4 × 200² + 2 × 200 × 800)

= 2,000,000

Runs on your CPU

WASM kernels and an approximately 8 MB checkpoint make local experiments accessible. Runtime memory includes activations and the interpreter; 8 MB is the weight file size.

Every result is inspectable

Two thousand pretraining updates and one thousand refinement updates. The checkpoint was selected by validation loss. All forty reserved generations, including failures, are published.

No broad benchmark, speed superiority or general reasoning claim is made. Evaluation topics and target answers overlap with training; new wording remains a challenge.
